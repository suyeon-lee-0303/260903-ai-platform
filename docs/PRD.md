# 프로젝트 목적

Senior AI Hub는 AI 상담에서 끝나는 서비스가 아니라,

AI가 사용자의 질문을 이해하고

맞춤형 학습 방향을 추천한 후

무료 체험 신청까지 연결하는 AI 교육 플랫폼이다.

이번 개발에서는

기존 프로젝트를 유지하면서

"AI 맞춤 학습 추천"

기능을 추가한다.

---

# 개발 원칙

기존 프로젝트를 분석한 후 작업한다.

기존 기능은 삭제하지 않는다.

작동하는 기능은 수정하지 않는다.

필요한 기능만 추가한다.

기존 UI 스타일을 유지한다.

---

# 현재 구현 완료 기능

다음 기능은 이미 정상 동작한다.

- AI 상담
- Claude API 호출
- 무료 체험 신청
- Google Sheets 저장
- 모바일 반응형
- 신청 완료 화면

이 기능들은 그대로 유지한다.

---

기존 프로젝트에

# Acceptance Criteria

## AI 상담

사용자가 질문하면

Claude 답변이 정상 출력된다.

---

## AI 추천

상담 완료 후

추천 카드가 자동 표시된다.

추천 카드에는

- 현재 수준
- 추천 과정
- 추천 이유
- 다음 추천 과정

이 표시된다.

---

## 신청

신청 데이터를

Google Sheets에 저장한다.

완료 화면을 표시한다.

# 구현 방법

기존 Claude API 호출 결과를 활용하거나,

필요하면 Claude API를 한 번 더 호출하여

추천 내용을 생성한다.

기존 API 구조는 변경하지 않는다.

Google Sheets 구조는 변경하지 않는다.

---

# 개발 금지 사항

다음 작업은 하지 않는다.

- React로 변경
- 기존 UI 전체 수정
- Google Apps Script 제거
- Claude API 구조 변경
- 신청 폼 구조 변경
- 새 프로젝트 생성

# 완료 조건

□ 기존 기능 오류 없음

□ 모바일 정상 작동

□ 기존 디자인 유지
