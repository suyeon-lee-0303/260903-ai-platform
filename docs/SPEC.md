# 프로젝트 개요

Senior AI Hub는 생성형 AI가 처음인 40~70대 성인과 시니어를 위한 AI 교육 상담 웹앱입니다.

사용자는 AI에게 궁금한 점을 질문하고,

AI가 쉬운 말로 답변한 뒤,

사용자에게 맞는 학습 방향을 추천하고,

무료 체험 교육까지 신청할 수 있습니다.

이 프로젝트는 실제 운영 예정인

**디지털이음 AI교육원**의 MVP입니다.

---

# 프로젝트 목표

기존 프로젝트를 유지하면서

AI 상담 이후

"AI 맞춤 학습 추천"

기능을 추가하여

더 자연스러운 사용자 경험을 만드는 것이 목표입니다.

---

# 중요한 개발 원칙

이 프로젝트는

새 프로젝트를 만드는 것이 아닙니다.

기존 프로젝트를 개선합니다.

현재 정상적으로 동작하는 기능은

절대 삭제하거나

다시 구현하지 않습니다.

기존 구조를 최대한 유지하면서

필요한 기능만 추가합니다.

---

# 현재 구현되어 있는 기능

현재 프로젝트에는 아래 기능이 이미 구현되어 있습니다.

✅ AI 상담 (Claude API)

✅ 무료 체험 신청

✅ Google Sheets 저장

✅ 모바일 반응형

✅ Netlify 배포

이 기능들은 모두 유지합니다.

---

# 추가할 기능

## AI 맞춤 학습 추천

AI 상담이 끝난 후

Claude가 상담 내용을 분석하여

아래 내용을 생성합니다.

- 현재 수준
- 추천 과정
- 추천 이유
- 다음에 배우면 좋은 과정

예시

현재 수준

AI 입문

추천 과정

AI 입문반

추천 이유

생성형 AI를 처음 시작하는 단계입니다.

스마트폰 활용 경험이 있으므로

입문 과정부터 시작하는 것이 좋습니다.

다음 추천 과정

ChatGPT 기초

기존 색상

# Cursor 작업 지침

프로젝트를 먼저 분석합니다.

기존 코드를 삭제하지 않습니다.

기존 기능을 다시 만들지 않습니다.

작동하는 기능은 수정하지 않습니다.

새 기능만 추가합니다.

한 번에 하나의 기능만 구현합니다.

기능 구현 후 테스트를 진행합니다.

모든 작업은 기존 프로젝트를 기반으로 진행합니다.
