# 목적

현재 UI를 유지하면서

사용자 경험을 개선한다.

새로운 디자인을 만드는 것이 아니다.

현재 디자인 스타일을 유지하면서

AI 맞춤 학습 추천 카드만 추가한다.

---

# 반드시 지켜야 하는 사항

현재 프로젝트의 디자인은 수정하지 않는다.

아래 요소는 그대로 유지한다.

- Hero 영역
- 색상
- 버튼 스타일
- 카드 디자인
- 폰트
- 여백
- 모바일 UI

새로운 디자인 시스템을 적용하지 않는다.

# 개발 원칙

현재 디자인를 존중한다.

새로운 UI를 만들지 않는다.

기존 CSS를 최대한 재사용한다.

HTML 구조를 크게 변경하지 않는다.

필요한 div만 추가한다.

기존 JavaScript 구조를 유지한다.

기존 함수를 삭제하지 않는다.

필요한 함수만 추가한다.

---

# Cursor 작업 지침

현재 index.html을 분석한다.

현재 CSS를 재사용한다.

현재 JavaScript를 재사용한다.

기존 기능을 수정하지 않는다.

AI 추천 카드만 추가한다.

모든 변경은 최소한으로 한다.

기존 사용자가 달라졌다고 느끼지 않을 정도로 자연스럽게 기능을 추가한다.
